
# Manual de Uso
## Escáner de Puertos TCP en Python

## 1. Descripción

El Escáner de Puertos TCP es una aplicación básica desarrollada en Python
que permite comprobar qué puertos TCP se encuentran abiertos dentro de un
rango especificado por el usuario.

La herramienta fue desarrollada con fines académicos para la asignatura
Seguridad Informática.

---

## 2. Requisitos

Para ejecutar la aplicación se necesita:

- Computadora con Windows, Linux o macOS.
- Python 3 instalado.
- Visual Studio Code o una terminal.
- Archivo scanner_puertos.py.

Para comprobar que Python está instalado se puede ejecutar:

```bash
python --version
